# Merch photos

Put the t-shirt pictures in this folder. Each main-roster player needs two files:

- `<name>-front.png`
- `<name>-back.png`

where `<name>` is the player name in lowercase letters and numbers only:

| Player | Files |
|---|---|
| GHEOPARD | `gheopard-front.png`, `gheopard-back.png` |
| Ceontixx | `ceontixx-front.png`, `ceontixx-back.png` |
| stfandrei | `stfandrei-front.png`, `stfandrei-back.png` |
| REGELE | `regele-front.png`, `regele-back.png` |
| teaca | `teaca-front.png`, `teaca-back.png` |

The site also accepts `.jpg`, `.jpeg` and `.webp` with the same names.
Tip: keep each picture under about 300 KB (800 x 1000 px is plenty).
Until a picture exists, the site shows a drawn placeholder t-shirt.
